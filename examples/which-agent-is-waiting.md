# Which agent is waiting for you?

Try three read-only tasks. Two finish on their own. The third asks you a question on your phone, and your answer comes back to its original session.

## Set up the exercise

1. Pair the Pushary app with a supported agent using the [setup guide](https://pushary.com/docs/agents/quickstart?utm_source=github&utm_medium=exercise&utm_campaign=phone_answer&utm_content=three_agent_setup).
2. Open three separate sessions. Use a scratch folder or a blank workspace for each. The tasks below use only the text you provide.
3. Paste one prompt into each session. Leave all three running and step away from the computer.

**Session one**

```text
Sort these three titles alphabetically and print the result: Notes, Plan,
Checklist. Use only this text. Keep the task read-only.
```

**Session two**

```text
Count the words in this sentence and print the answer: A draft is ready for
review. Use only this text. Keep the task read-only.
```

**Session three**

```text
Use Pushary to ask me which format I want for this summary: bullets or a
paragraph. Wait for my phone answer and repeat the exact option I chose in
this session. Keep this test read-only.
```

## What to check

Open the notification on your paired phone and answer the format question. Back at the computer, look for your answer in session three and the completed results in the other two. If the question does not arrive, use the [delivery checks](https://pushary.com/docs/agents/reference/troubleshooting?utm_source=github&utm_medium=exercise&utm_campaign=phone_answer&utm_content=three_agent_help).
